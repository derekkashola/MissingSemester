# Missing Semester

My work through [The Missing Semester of Your CS Education](https://missing.csail.mit.edu)
(MIT). This is Project 1-A of my *From Zero to the Metal* roadmap — building
command-line fluency before the C, Rust, and kernel work later on.

## Layout

```
notes/       # what I learned, one file per topic
exercises/   # code I wrote to prove it (scripts, solutions)
DEVLOG.md    # running log of what I did and what broke
```
